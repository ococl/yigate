WebUI 尚未构建

当前二进制中嵌入的是占位页面，说明构建时没有把前端产物放入 src/proxy/webui_dist。

请先构建前端，再重新编译 Go 程序：

cd web && npm install && npm run build cd .. && rm -rf src/proxy/webui_dist && mkdir -p src/proxy/webui_dist cp -r web/dist/* src/proxy/webui_dist/ cd src && go build -o yigate .

或者直接使用 make build / Docker 构建，二者会自动完成前端集成。

管理 API 仍然可用，例如 GET /health。详见项目 README 与 API 文档。
