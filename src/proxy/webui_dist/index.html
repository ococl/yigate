YiGate WebUI 未构建

当前二进制是用仓库内的占位页面构建的，管理 API 可正常使用，但内置前端尚未打包。

构建带前端的二进制：

make build          # 构建前端 → 压缩嵌入 src/proxy/webui_dist → 编译 Go 二进制

或者仅构建前端后重新编译：

cd web && npm ci && npm run build
cd .. && node web/scripts/embed-dist.mjs web/dist src/proxy/webui_dist
cd src && go build -o ../build/yigate .
  1. 直接使用官方镜像即可获得完整前端： docker compose up -d（镜像内会构建前端）。
  2. 构建完成后如需保持工作区干净，可恢复占位页： git checkout -- src/proxy/webui_dist/index.html。
  3. 不想启用前端时，可在配置中设置 webui.enabled: false， 管理端口将仅提供 API。
